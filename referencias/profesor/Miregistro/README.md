# Referencia de clase: Miregistro

Este directorio conserva como **referencia académica** el proyecto Android `Miregistro` compartido durante las clases.

Su propósito es ayudarnos a mantener el desarrollo de `SeguimientoSiniestros` alineado con la forma de trabajo mostrada en clases, especialmente en la organización de una aplicación Jetpack Compose.

## Qué observamos en esta referencia

- proyecto Android con Kotlin y Kotlin DSL;
- Jetpack Compose y Material Design 3;
- Minimum SDK 24;
- recursos Android organizados en `res/`;
- tema separado en `ui/theme`;
- dimensiones reutilizables mediante `Dimens.kt`;
- estilos reutilizables en `ui/styles`;
- componentes reutilizables en `ui/components`;
- strings y content descriptions declarados en recursos;
- pruebas de ejemplo de Android Studio.

Algunos paquetes como `model`, `viewmodel` y `ui/screens` aparecen preparados en la estructura aunque el proyecto entregado no contiene todavía una aplicación funcional completa en esas carpetas.

## Archivo del proyecto

El proyecto limpio se conserva en:

`Miregistro_referencia_limpia.zip`

Se eliminaron únicamente archivos locales o generados que no deben versionarse como referencia:

- `.gradle/`
- `.idea/`
- `local.properties`
- directorios `build/`

El código y los recursos propios del proyecto permanecen dentro del ZIP.

## Cómo utilizar esta referencia

Esta referencia **no reemplaza la pauta, el caso oficial ni DOCUMENTACION.md** y tampoco forma parte de la compilación de `SeguimientoSiniestros`.

Cuando implementemos una tarea de Trello podemos consultar `Miregistro` para imitar patrones de organización y presentación vistos en clases, pero las funcionalidades finales deben responder al caso de siniestros y a la pauta de evaluación.
